# Employee directory design

Task-focused Bootstrap interface for routine employee management. Preserve the
simple styling and familiar table/form conventions.

- White workspace panels on #f4f6f5; text #20312e; green primary #17634d.
- Bootstrap system body typography, 32px page heading, 14px table content.
- Maximum page width 1400px; desktop gutters 40px, mobile gutters 18px.
- Single table panel with search above and pagination below. No decorative charts.
- Two-column employee form on desktop, single column below 768px.
- Bootstrap dialogs provide focus trapping, static backdrop and explicit cancel.
- Escape closes when no request is pending; mutations disable form controls.
- Inline server validation and visible loading, empty, connection-error states.
- Employee status uses text as well as color. Passwords never appear in details.
